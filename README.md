# NYSC Batch Congratulations Card Generator

An automated card-generation tool built for the NCCF (Nigeria Christian Corpers' Fellowship) family to replace a slow, manual design process during Passing Out Parade (POP) season.

🔗 Live app: https://batch-25.vercel.app

## The Problem
Whenever corp members in the fellowship completed their service year (POP), the tradition was to design a personalized congratulations card for every corper in that batch and stream. With batches sometimes exceeding 20 members, manually designing each card in graphic design software was slow and labor-intensive — often falling on one or two volunteers to handle alone.

## The Solution
This web app lets each passing-out corp member fill in their own details and upload their picture, then automatically generates a ready-to-download, ready-to-post congratulations card — no manual design work required. What used to take hours of one-by-one design work now takes each person a couple of minutes to self-serve.

## Features
- Simple form for entering personal details (name, batch, stream, etc.)
- Photo upload, auto-placed into the card template
- Instant card generation
- One-click download, ready for sharing on social media

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Installation
```bash
git clone https://github.com/Annyjerry/NYSC-CARD.git
cd NYSC-CARD
```
Open `index.html` in your browser, or serve it locally with any static server.

## Usage
1. Open the app
2. Fill in your name, batch, and stream details
3. Upload your photo
4. Generate and download your personalized card

## Impact
Turned a manually intensive, hours-long group task into a self-service tool corp members could use in minutes — built to solve a real problem for a real community.
